# Fonts shipped with the skins

Free fonts the built-in skins name with `@font-face`, so they look the same on every computer. Each is
shipped unmodified, under its own licence (in this folder).

| Files | Family | Used by | From | Licence |
|---|---|---|---|---|
| `selawk.ttf`, `selawkb.ttf`, `selawksb.ttf` | Selawik (regular, bold, semibold) | the 7 skin | the Selawik project, release 1.01 (an open-source substitute for a 2009-era system font) | SIL Open Font License 1.1: `Selawik-LICENSE.txt` |
| `tahoma.ttf`, `tahomabd.ttf` | Tahoma (regular, bold): the Wine project's own font, metric-compatible with the classic face of that name | the XP skin, and the 90s skin (unsmoothed) | Wine 10.0, as packaged by Debian (`fonts-wine`) | GNU LGPL 2.1 or later (Copyright (c) 1993-2022 Wine project authors): `Tahoma-LGPL-2.1.txt` |
| `rajdhani.ttf`, `rajdhanib.ttf` | Rajdhani (regular, bold): a squared, condensed technical sans | the Neon District skin | Indian Type Foundry, version 1.201, from the Google Fonts repository (`ofl/rajdhani`) | SIL Open Font License 1.1: `Rajdhani-LICENSE.txt` |
